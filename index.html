Hospital visit

Export and backup

Your answers stay in this browser on this iPad. Export regularly. The CSV can be opened in Excel or Numbers.

How to use on iPad
  1. Open this file in Safari (not only the Files preview). Use Share → Open in Safari if needed.
  2. Select a hospital and enter answers. Changes save automatically in this browser.
  3. Tap Export all responses to create a CSV, then open it in Excel or Numbers.
  4. Use Backup data before switching devices or clearing Safari website data.

This is a local form and does not send your hospital information to a server. Keep using the same Safari browser on this iPad.
